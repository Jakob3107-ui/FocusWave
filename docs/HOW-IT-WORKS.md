# How FocusWave works

FocusWave is Fedora 45 KDE Plasma plus five small pieces. It never patches Plasma itself, so Fedora updates keep working.

```
                    ┌──────────────── Customize app / Welcome tour (PySide6 + Kirigami)
                    │                     │ writes ~/.config/focuswave/state.json
                    ▼                     ▼
              focuswave engine (Python) ── kwriteconfig6 · plasma-apply-colorscheme ·
                    │                      plasmashell scripts · KWin reconfigure
                    │
   Meta+F ─┐        ▼
  top bar ─┼──► KWin script "focuswave-focus" ──D-Bus──► focuswave-focus-overlay (C++/Qt)
win menu ──┘     (who is focused, stacking,               one transparent window per screen
                  fade, follow app switching)             that asks KWin for blur-behind
```

## Base: why Fedora KDE Plasma

- **Plasma 6 is the most customizable desktop available**, and almost everything can be scripted, so the Customize app can change it live.
- **Fedora 45** ships kernel 7.x and Mesa 26, which support the i7‑1355U (Raptor Lake) and Iris Xe out of the box. Its Wayland session gives smooth, tear‑free animations.
- Fedora is updated quickly, and its signed bootloader works with Secure Boot.

## Focus Mode

Writing a brand‑new blur shader inside the compositor was the obvious approach. FocusWave avoids it on purpose:

- KWin's C++ effect API changes with almost every Plasma release, so a custom effect would break after updates.
- A bug in a compositor plugin takes the whole desktop down.

Instead, Focus Mode reuses **KWin's own blur**, the same GPU blur (dual Kawase) that panels and menus use, so it's proven smooth on Iris Xe:

1. **`focuswave-focus-overlay`** (C++, ~250 lines, started on demand over D‑Bus). It opens one transparent full‑screen window per screen. Each window asks KWin for blur‑behind, so everything underneath gets blurred. It can also tint the overlay to darken the background. It sets KWin's blur strength to the Focus Mode strength while active and restores the normal value afterwards.
2. **KWin script `focuswave-focus`** (JavaScript). It registers **Meta+F** and the window‑menu entry and finds the window to focus. It keeps the stacking right: other windows < blur overlay < focused window (and its dialogs, via *keep above*). It fades the overlay in and out, using a D‑Bus "wait" call as a timer. It follows Alt+Tab and dock clicks, and exits when the window closes, is minimized, or you switch virtual desktops.
3. **Top‑bar button** (`org.focuswave.focustoggle` plasmoid). It triggers the same global shortcut, so there is one code path.

*Keep dock visible* puts the overlay below Plasma's panel layer. Turning it off puts the overlay above the panels.

## Look & feel

- **Color schemes:** `FocusWaveLight` and `FocusWaveDark`, generated by `tools/gen_colors.py`. The title bar matches the window background for a unified macOS‑style look, and the accent color comes from Plasma's accent setting.
- **Wallpapers:** three Plasma wallpaper packages, each with an `images_dark/` variant that Plasma uses automatically in dark mode. They're rendered by `tools/gen_wallpapers.py`.
- **Window buttons:** *traffic lights* come from `focuswave-decoration`, a small KDecoration3 plugin with rounded corners, a soft shadow, and colored buttons that show glyphs on hover. *Windows style* uses Breeze with the buttons on the right. The plugin is a separate, optional package; without it, the engine uses Breeze with the buttons on the left.
- **Layouts:** `layouts.py` writes a Plasma desktop script. The same script is the default layout of the `org.focuswave.desktop` global theme, so the ISO's default desktop and the Customize app's presets are identical.
- **Browser:** Zen is installed from Flathub during the ISO build, together with the Intel VA‑API and ffmpeg extensions that match its runtime. `mimeapps.list` makes it the default browser and falls back to Firefox, and the dock pins `preferred://browser`, so it always shows whichever browser is the default. Firefox is removed only if Zen installed successfully.
- **System defaults:** `/usr/share/focuswave/xdg/` holds kdeglobals, kwinrc and others. `/etc/xdg/plasma-workspace/env/focuswave.sh` puts that folder at the front of `XDG_CONFIG_DIRS`. These defaults only apply until a user changes something, and they disappear cleanly when the package is removed.

## Customize app & engine

- All of FocusWave's look is one JSON document (`~/.config/focuswave/state.json`).
- The engine (`engine.py`) applies one category at a time: colors, wallpaper, buttons, windows, fonts, focus, layout. It uses only Plasma's own tools: `kwriteconfig6 --notify`, `plasma-apply-colorscheme`, `plasma-changeicons`, `org.kde.PlasmaShell.evaluateScript`, and KWin `reconfigure`.
- The app debounces changes (350 ms) and applies them in the background, so sliders stay smooth. Layout changes wait for **Apply to my desktop**, because they rebuild the panels.
- **Automatic light/dark:** a systemd user timer runs `focuswave-theme auto` every 10 minutes and at login. It only does anything when the mode should switch.
- **Themes** are saved copies of the state, with custom wallpapers copied in. `.fwtheme` files are zips containing `theme.json` and the wallpaper.
- `focuswave-theme` exposes the same engine on the command line: `set mode dark`, `set accent "#ff6b9d"`, `export look.fwtheme`, and so on.

## Performance choices for the i7‑1355U / 16 GB / Iris Xe

| Choice | Why |
|---|---|
| Wayland session, KWin blur/scale effects only | GPU‑accelerated, tear‑free, low CPU |
| No splash screen (`ksplashrc`) | faster login |
| Baloo indexes file **names** only | fast search without background CPU/battery drain |
| `thermald` enabled | Intel's thermal daemon; better sustained performance and fan behavior on U‑series chips |
| `NetworkManager-wait-online` and `dnf-makecache.timer` disabled | faster boot, fewer background wake‑ups |
| `intel-media-driver` (RPM Fusion) + full `ffmpeg` | hardware video decoding (YouTube, local videos) = much better battery life |
| zram swap (Fedora default) | 16 GB goes further, no SSD wear |
| Animation speed 0.75× | feels snappier |
| Focus Mode helper starts only when used and quits after 10 idle minutes | zero cost when you don't use it |
| No PIM suite (Akonadi), no bundled games | less RAM at login |
| Zen Browser (Firefox engine) instead of a Chromium browser | Gecko generally needs less RAM than Chrome‑based browsers, and VA‑API video decoding keeps CPU use and heat down |

## Troubleshooting

| Problem | Try |
|---|---|
| Meta+F does nothing | Settings → Window Management → KWin Scripts → make sure **FocusWave Focus Mode** is ticked. Check that the shortcut isn't taken in Settings → Shortcuts → KWin. Logs: `journalctl --user -b \| grep -i focuswave` |
| Focus Mode shows no blur | Settings → Desktop Effects → **Blur** must be enabled. In a VM without 3D acceleration, blur may be off. |
| Traffic lights don't appear | `rpm -q focuswave-decoration`. If it's missing, the plugin didn't build; windows use Breeze buttons on the left instead. |
| Customize won't open | Run `focuswave-customize` in Konsole and read the error (often a missing `python3-pyside6` or `kf6-kirigami`). |
| Layout looks wrong after an update | Customize → Layout → **Apply to my desktop**, or Advanced → **Reset to FocusWave defaults** |
| Want stock KDE back | `bash ./setup/focuswave-setup.sh uninstall` |
